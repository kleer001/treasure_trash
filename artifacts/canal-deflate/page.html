Cargo into the canal

The same shove, played on two builds. A skateboard is pinned against a wall, so its load tips backward — into open water, which keeps it. The board does exactly the same thing in both. Only the drawing changed.

The shove, both ways

Why it changed

Leaving the board used to be said two ways. A thing taken by water said so with an adjective — an effect string on the entry that moved it — which the renderer translated into removal by testing that string against a list it kept by hand. A thing that fell through a grate said so by appearing in the gone lane instead.

Every removal is now a gone entry, and effect means only how a thing leaves. Nothing reads a string to find out whether something survived.

Before — the removal is an adjective 
moved: [{ o: TRASH, from: [2,1], to: [1,1], effect: 'fills', depth: 0 }]
gone : []
After — the removal is an entry 
moved: [{ handle: '2,1/0', cells: [[2,1]], o: TRASH, dx: -1, dy: 0, becomes: {…} }]
gone : [{ handle: '2,1/0', cells: [[2,1]], o: TRASH }]

What did not change

Both builds walk the board from #-x## to #--## — the same transition, verified on each. The spill was always removed at the end of that journey. The old account simply had no way to say travelled, and then taken as two facts, so the renderer dropped the sprite where it stood rather than carrying it across and letting it go.
